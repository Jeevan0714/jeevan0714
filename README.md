## 🧬 Who Am I?

| 🤖 | **Embedded Systems** | Agrobot Firmware · IoT Sensor Telemetry · Real-Time MCU Scheduling |
| 🎯 | **Mission** | Open-source silicon · energy-efficient compute · smart edge systems |

<summary><h3>&nbsp;🔢&nbsp; Modified Booth Multiplier — SkyWater 130nm VLSI Design</h3></summary>

<br/>

<div align="center">

```
╔══════════════════════════════════════════════════════════════════╗
║   High-Speed Signed Binary Multiplier — Radix-4 Booth (Sky130)   ║
║        Partial Product Reduction · Low Latency · OpenROAD        ║
╚══════════════════════════════════════════════════════════════════╝
```

</div>

> Hardware implementation of the **Modified Booth's Algorithm (Radix-4)** for signed binary multiplication, synthesized and taped out on the **SkyWater 130nm (Sky130)** open-source PDK. Radix-4 encoding halves partial products — delivering a significant speed and area advantage over naive multiplier implementations.

**Highlights:**
- ➗ Radix-4 Booth encoding for 50% partial product reduction
- 🚀 Wallace/Dadda tree compression for minimum critical path delay
- 📐 Physical implementation on **SkyWater Sky130** using **OpenROAD** open-source flow
- ✅ Verified against software golden model across all signed/unsigned edge cases
