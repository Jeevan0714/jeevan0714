## 🛠️ About Me

👋 Hello! I am a **Hardware Design & Embedded Systems Engineer** passionate about building high-performance computer architectures, custom processor cores, and ASIC implementations.

- ⚙️ **Core Specialization**: RISC-V Processor Cores (RV32IM), Verilog / SystemVerilog HDL, and Self-Checking Verification Frameworks.
- 🔬 **Silicon Design**: Design & ASIC Implementation of Integrated Pseudorandom Generators (LFSR/NFSR) in **45nm technology node**.

- 🤖 **Embedded Robotics**: Autonomous Agrobot platforms & IoT-enabled smart systems.
- 🎯 **Goal**: Advancing open-source silicon engineering and energy-efficient hardware compute.
