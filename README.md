<details open>
<summary><h3>&nbsp;🔢&nbsp; Modified Booth Multiplier — VLSI Arithmetic Unit</h3></summary>

<br/>

<div align="center">

```
╔══════════════════════════════════════════════════════════════════╗
║     High-Speed Signed Binary Multiplier — Radix-4 Booth          ║
║        Partial Product Reduction · Low Latency Pipeline          ║
╚══════════════════════════════════════════════════════════════════╝
```

</div>

> Hardware implementation of the **Modified Booth's Algorithm (Radix-4)** for signed binary multiplication. By encoding partial products, the design halves the number of additions required — delivering a significant speed and area advantage over naive multiplier implementations in hardware arithmetic units.

**Highlights:**
- ➗ Radix-4 Booth encoding for 50% partial product reduction
- 🚀 Wallace/Dadda tree compression for minimum critical path delay
- 📐 Synthesized for area and timing with standard cell library
- ✅ Verified against software golden model across all signed/unsigned edge cases
